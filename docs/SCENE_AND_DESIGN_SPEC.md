# SCENE & DESIGN SPEC — ซีน ตัวละคร ภาพ วิดีโอ และงานออกแบบ

## 1. ทิศทางงานภาพรวม

เว็บต้องให้ความรู้สึกว่าเป็น Creative Studio สำหรับคอนเทนต์ไลฟ์สด ไม่ใช่แบบฟอร์มธรรมดา

บุคลิกงานออกแบบ

- สดใส ทันสมัย เป็นมิตร
- ให้ความรู้สึกมืออาชีพและใช้งานง่าย
- เน้นภาพแนวตั้ง 9:16
- ให้ผู้ใช้เห็น Timeline และความต่อเนื่องของซีนชัดเจน
- มีพลังแบบคอนเทนต์ไลฟ์สด แต่ไม่รก
- ใช้ภาษาไทยทุกจุดอย่างถูกต้อง
- รองรับจอมือถือเป็นหลัก

องค์ประกอบภาพที่ควรใช้

- กรอบวิดีโอแนวตั้ง
- ไอคอนกล้อง ไมโครโฟน แสง และแชต
- การ์ดซีนแบบ Storyboard
- เส้น Timeline
- Badge แสดง 17–20 คำ
- Badge แสดงสถานะเสียง ภาพ และวิดีโอ
- Preview Safe Area

## 2. Design System

### 2.1 สี

กำหนดเป็น Design Token และเปลี่ยนได้จาก Brand Settings

- Primary: สีฟ้าสดหรือฟ้าน้ำทะเล
- Secondary: สีส้มอุ่น
- Accent: สีชมพูหรือม่วงสำหรับจุดเด่น
- Background: ครีมอ่อนหรือขาวนวล
- Surface: ขาว
- Text: น้ำตาลเข้มหรือเทาเข้ม
- Success: เขียว
- Warning: ส้ม
- Error: แดง

ห้ามใช้สีมากเกินไปในหน้าจอเดียว ควรมีสีหลักหนึ่งสีและ Accent สำหรับ CTA

### 2.2 ฟอนต์ไทย

ต้องใช้ฟอนต์ที่รองรับภาษาไทยครบ เช่นกลุ่มฟอนต์แนวอ่านง่ายและร่วมสมัย โดยต้องตรวจ

- สระบนและล่างไม่ชน
- วรรณยุกต์ไม่ลอย
- ตัวเลขอ่านชัด
- น้ำหนัก Regular, Medium, SemiBold, Bold ใช้งานได้

ห้ามให้โมเดลสร้างภาพวาดตัวหนังสือไทยลงในภาพโดยตรง ข้อความไทยทุกชิ้นต้อง Overlay ภายหลังด้วยระบบเว็บ

### 2.3 การ์ด

- มุมโค้งระดับกลาง
- เงาเบา
- ระยะห่างชัด
- มี Header ของซีน
- มีสถานะและปุ่มคำสั่ง
- รองรับ Collapsed/Expanded

## 3. ตัวละครหลัก

### 3.1 ค่าเริ่มต้น

- ผู้หญิงไทยอายุ 25–27 ปี
- หน้าตาเป็นมิตร น่าเชื่อถือ และมั่นใจ
- ผิวและสัดส่วนเป็นธรรมชาติ
- แต่งหน้าเหมาะกับงานไลฟ์สด
- ทรงผมเรียบร้อยแต่ทันสมัย
- การแสดงมีพลัง ไม่แข็ง ไม่เกินจริง
- สบตากล้องเหมือนกำลังพูดกับผู้ชมจริง

### 3.2 Character Presets

1. แม่ค้าไลฟ์มืออาชีพ
2. เจ้าของโกดังรุ่นใหม่
3. สาวสวนทุเรียน
4. แม่ค้าผลไม้สด
5. ผู้เชี่ยวชาญพระเครื่อง
6. เจ้าของร้านแฟชั่น
7. Beauty Creator
8. เจ้าของร้านของใช้ในบ้าน
9. เจ้าของร้านแก็ดเจ็ต
10. แม่ค้าออนไลน์มือใหม่

แต่ละ Preset ต้องกำหนด

- อายุ
- ทรงผม
- เครื่องแต่งกาย
- บุคลิก
- ท่าทางหลัก
- โทนเสียง
- สถานที่ที่เข้ากัน
- Props
- สีประจำตัวละคร

### 3.3 Character Lock

เมื่อเปิด Character Lock ต้องส่งรายละเอียดเดิมไปทุกซีน

- Character ID
- Face Description
- Hair
- Clothing
- Accessories
- Body Proportion
- Makeup
- Skin Tone
- Distinctive Features

## 4. Scene Library

### 4.1 โกดังสินค้าสต๊อก

ภาพรวม

- ชั้นวางสินค้าและกล่องพัสดุจำนวนมาก
- โต๊ะแพ็กสินค้า
- ไฟสตูดิโอและโทรศัพท์สำหรับไลฟ์
- ทีมงานด้านหลังเคลื่อนไหวเบา ๆ
- ให้ความรู้สึกว่าร้านมีสินค้าและทำงานจริง

ไอเดียซีน

- แม่ค้าเดินผ่านชั้นสินค้าแล้วหยุดหน้ากล้อง
- เตรียมสินค้าเป็นกองก่อนเริ่มไลฟ์
- ห้องไลฟ์ช่วงแรกดูเงียบ
- บรรยากาศค่อย ๆ มีพลังขึ้น
- แม่ค้าพูดคล่องและหยิบสินค้ารีวิวต่อเนื่อง
- ปิดซีนด้วยมุมกว้างเห็นโกดัง

### 4.2 ทุเรียน

ภาพรวม

- สวนทุเรียนหรือจุดคัดทุเรียน
- ทุเรียนหมอนทองวางบนโต๊ะ
- มีถุงมือ มีด และกล่องบรรจุ
- สีภาพอุ่น สด และน่ากิน

ไอเดียซีน

- เคาะทุเรียนเลือกผลสวย
- เปิดเนื้อทุเรียนให้กล้องดู
- แม่ค้ากังวลก่อนเริ่มไลฟ์
- บรรยากาศเปลี่ยนหลังเริ่มนำเสนอ
- Close-up เนื้อทุเรียน
- จบด้วยการชวนผู้ชมดูรายละเอียดสินค้า

### 4.3 ผลไม้สด

- ตลาดผลไม้
- สวนผลไม้
- รถเข็นผลไม้
- จุดแพ็กออเดอร์
- สีสันสดและมีหยดน้ำบนผลไม้

ซีนเด่น

- จัดตะกร้าผลไม้
- ชั่งน้ำหนัก
- หั่นชิม
- รีวิวความสด
- พาเดินดูสต๊อก

### 4.4 พระเครื่องและของสะสม

- โต๊ะไม้สะอาด
- กล่องใส่พระ
- แสงนุ่มไม่สะท้อนแรง
- กล้อง Macro สำหรับรายละเอียด
- บุคลิกผู้พูดสุขุมและน่าเชื่อถือ

ข้อควรระวัง

- ไม่กล่าวอ้างอิทธิฤทธิ์หรือรับประกันผลเหนือธรรมชาติ
- ไม่กล่าวอ้างราคาแท้หรือความแท้ หากไม่มีข้อมูลตรวจสอบ
- ใช้คำว่าเล่ารายละเอียด ประวัติ และจุดสังเกต

### 4.5 เสื้อผ้า รองเท้า กางเกง

- ราวเสื้อผ้า
- กระจกเต็มตัว
- โต๊ะพับสินค้า
- ห้องลอง
- ชั้นรองเท้า
- แสงแฟชั่นสะอาด

ซีนเด่น

- เปลี่ยนลุคก่อนและหลัง
- หยิบสินค้าจากราว
- สาธิตเนื้อผ้า
- เดินให้ดูทรง
- Close-up ตะเข็บหรือพื้นรองเท้า

### 4.6 เครื่องสำอางและสกินแคร์

- โต๊ะเครื่องแป้ง
- กระจกไฟ
- ชั้นวางสินค้า
- Close-up เนื้อผลิตภัณฑ์
- แสงผิวสวยแต่ไม่แต่งภาพเกินจริง

ข้อควรระวัง

- ห้ามรับประกันผลรักษา
- ห้ามกล่าวอ้างทางการแพทย์โดยไม่มีหลักฐาน
- ไม่ใช้ภาพก่อนและหลังที่ทำให้เข้าใจผิด

### 4.7 ของใช้ในบ้านและอุปกรณ์ครัว

- ครัวสมัยใหม่
- บ้านสไตล์อบอุ่น
- โต๊ะสาธิตสินค้า
- แสดงการใช้งานจริงแบบเข้าใจง่าย

### 4.8 แก็ดเจ็ตและอุปกรณ์มือถือ

- โต๊ะเทคโนโลยี
- แสง Edge Light
- หน้าจอและอุปกรณ์เสริม
- ถ่าย Close-up ฟังก์ชัน

### 4.9 อาหาร ขนม และเครื่องดื่ม

- โต๊ะจัดอาหาร
- ครัวหรือร้านเล็ก
- Steam, Texture และ Close-up
- ห้ามทำอาหารดูผิดธรรมชาติ

### 4.10 สินค้าแม่และเด็ก

- บ้านอบอุ่น
- โทนสะอาดและปลอดภัย
- ห้ามกล่าวอ้างผลด้านสุขภาพเกินจริง
- หลีกเลี่ยงการใช้เด็กเป็นผู้รีวิวสินค้าเสี่ยง

## 5. โครงซีนไวรัล

### แบบ A: ก่อน–หลังอย่างรับผิดชอบ

1. Hook: ห้องไลฟ์เงียบและแม่ค้ากังวล
2. Problem: พูดคนเดียวจนเสียความมั่นใจ
3. Discovery: ทดลองเครื่องมือจาก pumlikes.com
4. Change: บรรยากาศดูมีชีวิตขึ้น
5. Result: แม่ค้านำเสนอได้มั่นใจขึ้น
6. CTA: ชวนดูรายละเอียดตามความเหมาะสม

ห้ามสื่อว่าระบบรับประกันยอดขายหรือผู้ชมเป็นลูกค้าจริง

### แบบ B: ละครสั้นเศร้า–ตื่นเต้น–อบอุ่น

1. แม่ค้านั่งเงียบหลังปิดไลฟ์
2. คิดจะเลิกขาย
3. เพื่อนแนะนำวิธีปรับบรรยากาศ
4. ทดลองเตรียมไลฟ์ใหม่
5. เริ่มต้นอย่างตื่นเต้น
6. แม่ค้ากลับมามั่นใจ
7. จบด้วยกำลังใจ ไม่จบด้วยคำรับประกันยอดขาย

### แบบ C: POV แม่ค้า

- เปิดด้วยมือถือและโต๊ะสินค้า
- มุมกล้องเหมือนผู้ชมอยู่ในไลฟ์
- สลับ Close-up สินค้าและสีหน้า
- ข้อความบนจอสั้น กระชับ

### แบบ D: เบื้องหลังโกดัง

- เดินผ่านสต๊อก
- ทีมแพ็กของ
- เตรียมกล้อง
- เริ่มไลฟ์
- รีวิวบริการแบบเป็นธรรมชาติ

### แบบ E: รีวิว 3 เหตุผล

1. เริ่มไลฟ์ได้มั่นใจขึ้น
2. บรรยากาศดูมีชีวิตมากขึ้น
3. ช่วยให้เล่าเรื่องสินค้าได้ลื่นขึ้น

ใช้ถ้อยคำเชิงประสบการณ์ ไม่ใช้คำรับประกัน

ตัวอย่างโครง Prompt

`ภาพโฆษณาแนวตั้ง 9:16 ผู้หญิงไทยอายุ 25–27 ปี หน้าตาเป็นมิตรและมั่นใจ ยืนหน้ากล้องไลฟ์ในโกดังสินค้าที่เป็นระเบียบ กำลังหยิบสินค้าแนะนำด้วยท่าทางเป็นธรรมชาติ มีโทรศัพท์บนขาตั้ง ไฟวงแหวน กล่องสินค้าและทีมแพ็กของเบลออยู่ด้านหลัง มุม medium shot เลนส์ธรรมชาติ แสงอุ่นสะอาด รายละเอียดสูง เว้นพื้นที่ด้านบนและด้านล่างสำหรับข้อความไทย ไม่มีตัวอักษร ไม่มีโลโก้บิดเบี้ยว รักษาใบหน้า เสื้อผ้า และฉากให้เหมือนซีนก่อนหน้า`

## 8. Prompt วิดีโอ

ทุก Prompt วิดีโอต้องระบุ

- จุดเริ่มต้นภาพ
- การเคลื่อนไหวตัวละคร
- สีหน้า
- การหยิบจับสินค้า
- การเคลื่อนกล้อง
- Background Motion
- Duration
- Frame Rate ที่ต้องการ
- Lip-sync Notes
- End Frame
- Transition ไปซีนถัดไป
- ห้ามมีข้อความที่โมเดลวาดเอง

ตัวอย่าง

`วิดีโอแนวตั้ง 9:16 ความยาว 8 วินาที เริ่มจาก medium shot ผู้หญิงไทยอายุ 25–27 ปีในโกดังสินค้า เธอมองกล้องด้วยสีหน้ากังวลเล็กน้อย จากนั้นสูดหายใจ หยิบสินค้า และเริ่มพูดอย่างมั่นใจ กล้องค่อย ๆ dolly in อย่างนุ่มนวล ทีมแพ็กของด้านหลังขยับเล็กน้อย ปากตรงกับเสียงภาษาไทย ไม่มีเสียงพูดซ้อน ไม่มีตัวหนังสือในภาพ จบด้วย close-up สีหน้ามั่นใจเพื่อเชื่อมซีนถัดไป`

## 13. ตัวอย่างชุดไอเดียเริ่มต้น

### ไอเดีย 1 — โกดังที่กลับมามีพลัง

- Hook: แม่ค้าเดินผ่านกล่องสินค้าที่เตรียมไว้ แต่สีหน้ากังวล
- กลางเรื่อง: ทดลองปรับบรรยากาศไลฟ์ด้วย pumlikes.com
- จุดเด่น: กล้องค่อย ๆ เคลื่อนเข้าและฉากหลังเริ่มมีการทำงาน
- จบ: แม่ค้าพูดคล่องขึ้นและพาทีมทำงานต่อ

### ไอเดีย 2 — ทุเรียนลูกแรกของวัน

- Hook: แม่ค้าเคาะทุเรียน แต่ห้องไลฟ์ยังเงียบ
- กลางเรื่อง: เริ่มเปิดเนื้อทุเรียนและเล่ารายละเอียด
- จุดเปลี่ยน: บรรยากาศดูคึกคักขึ้น
- จบ: Close-up เนื้อทุเรียนและรอยยิ้มมั่นใจ

### ไอเดีย 3 — เสื้อสวยแต่ไม่มีแรงพูด

- Hook: ชุดเต็มราวแต่แม่ค้าเหนื่อย
- กลางเรื่อง: เปลี่ยนวิธีเริ่มไลฟ์และใช้บริการช่วยเสริมบรรยากาศ
- จบ: เดินโชว์ชุดอย่างมั่นใจ

### ไอเดีย 4 — พระเครื่องเล่าให้เข้าใจง่าย

- Hook: รายละเอียดเยอะและผู้พูดกังวลว่าจะอธิบายไม่ครบ
- กลางเรื่อง: ใช้ Macro Shot พร้อมเล่าเป็นช่วงสั้น
- จบ: ห้องไลฟ์ดูมีชีวิตและผู้พูดอธิบายต่อได้ลื่น

### ไอเดีย 5 — Beauty Creator มือใหม่

- Hook: ถือเครื่องสำอางแต่พูดติดขัด
- กลางเรื่อง: ทดลองจัดลำดับการนำเสนอและปรับบรรยากาศ
- จบ: สาธิตเนื้อผลิตภัณฑ์อย่างมั่นใจ โดยไม่รับประกันผลลัพธ์

### ไอเดีย 6 — รถเข็นผลไม้หน้าสวน

- Hook: รถเข็นเต็มแต่คนขายดูท้อ
- กลางเรื่อง: เปิดไลฟ์พาดูผลไม้ทีละชนิด
- จบ: บรรยากาศสนุกขึ้นและคนขายยิ้ม

### ไอเดีย 7 — รองเท้าคู่เดียวสามลุค

- Hook: ผู้ชมยังไม่เห็นความต่าง
- กลางเรื่อง: เปลี่ยนมุมกล้องและบรรยากาศ
- จบ: เดินโชว์สามลุคต่อเนื่อง

### ไอเดีย 8 — ห้องไลฟ์ 60 วินาทีแรก

- Hook: Countdown ก่อนเริ่ม
- กลางเรื่อง: แม่ค้าพูดประโยคเปิดที่เตรียมไว้
- จุดเปลี่ยน: Motion Graphic และ Product Highlight
- จบ: เข้าสู่การรีวิวเต็มรูปแบบ

### ไอเดีย 9 — เพื่อนถามว่าทำไมวันนี้มั่นใจ

- Hook: เพื่อนเดินเข้ามาถาม
- กลางเรื่อง: แม่ค้าเล่าประสบการณ์อย่างไม่ขายตรง
- จบ: ทั้งคู่เตรียมสินค้าและเริ่มไลฟ์

### ไอเดีย 10 — เกือบปิดร้านแต่ลองใหม่อีกครั้ง

- Hook: โทนเศร้าและเงียบ
- กลางเรื่อง: วางแผนคอนเทนต์ใหม่และทดลองเครื่องมือ
- จุดตื่นเต้น: เริ่มไลฟ์รอบใหม่
- จบ: ให้กำลังใจว่าอย่าหยุดพัฒนาวิธีนำเสนอ

## 14. Quality Checklist

ก่อนอนุมัติภาพหรือวิดีโอ ตรวจว่า

- ตัวละครยังเป็นคนเดิม
- อายุและภาพลักษณ์ไม่เปลี่ยน
- มือและนิ้วถูกต้อง
- สินค้าไม่ผิดรูป
- ฉากต่อเนื่อง
- แสงไม่เปลี่ยนโดยไม่มีเหตุผล
- ปากตรงกับเสียง
- ไม่มีตัวอักษรไทยผิดในภาพ
- Overlay อ่านได้
- Subtitle ไม่บังสินค้า
- ไม่มีคำกล่าวอ้างเกินจริง
- ไม่มี UI ที่ทำให้เข้าใจว่าเป็นข้อมูลจริง
- ไม่มี Watermark จาก Provider

## 15. Acceptance Criteria

- มี Template อย่างน้อย 30 แบบ

- ทุก Prompt ระบุ 9:16 และ No Embedded Text
- วางข้อความไทยภายหลังได้
- Preview Safe Area ได้
- เลือก Animation แยกแต่ละซีนได้
- Export Prompt ภาพและวิดีโอแยกกันได้
- มี Quality Checklist ก่อน Export
