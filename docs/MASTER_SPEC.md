# MASTER SPEC — Prompt Pumlikes Web Application

## 1. เป้าหมายของระบบ

สร้างเว็บแอปภาษาไทยสำหรับช่วยผู้ใช้คิดและสร้างชุดคอนเทนต์รีวิวบริการเพิ่มการมองเห็นไลฟ์สดของเว็บไซต์ `pumlikes.com` โดยระบบต้องสร้างผลลัพธ์ได้ครบในงานเดียว ได้แก่

- แนวคิดคอนเทนต์
- โครงเรื่องและลำดับซีน
- Prompt สำหรับสร้างภาพ
- Prompt สำหรับสร้างวิดีโอ
- บทพูดภาษาไทย
- คำอ่านสำหรับระบบเสียง AI
- ข้อความบนจอ
- ซับไตเติล
- คำอธิบายท่าทาง สีหน้า มุมกล้อง และการเคลื่อนกล้อง
- เอฟเฟกต์ แอนิเมชัน และเสียงประกอบ
- Caption สำหรับโพสต์
- ข้อควรหลีกเลี่ยงด้านนโยบายแพลตฟอร์ม

ระบบต้องเน้นการสร้างวิดีโอแนวตั้งสำหรับ TikTok, Facebook Reels, Instagram Reels, YouTube Shorts และสื่อโฆษณาแนวตั้ง โดยไม่สร้างข้อความที่กล่าวอ้างเกินจริงหรือเสี่ยงผิดกฎแพลตฟอร์ม

## 2. กลุ่มผู้ใช้เป้าหมาย

- เจ้าของร้านค้าออนไลน์
- ผู้ขายสินค้าแบบไลฟ์สด
- ทีมการตลาดของ `pumlikes.com`
- ผู้สร้างโฆษณาวิดีโอสั้น
- แอดมินที่ต้องการสร้างหลายเวอร์ชันอย่างรวดเร็ว
- ผู้ใช้ทั่วไปที่ไม่มีความรู้ด้าน Prompt Engineering

## 3. รูปแบบการใช้งานหลัก

### 3.1 Quick Generate

ผู้ใช้เลือกข้อมูลสั้น ๆ แล้วกดสร้างทันที

1. เลือกหมวดสินค้า

ระบบต้องคืนผลลัพธ์ครบทุกซีน พร้อมปุ่มคัดลอกแต่ละส่วน

### 3.2 Advanced Studio

สำหรับผู้ใช้ที่ต้องการควบคุมรายละเอียด

- ล็อกตัวละคร
- ล็อกฉาก
- ล็อกสินค้า
- กำหนดเสื้อผ้า
- กำหนดแสง

- กำหนดจำนวนคำพูด
- แก้ข้อความแสดงผลและคำอ่านแยกกัน
- เรียงซีนด้วย Drag and Drop
- Duplicate ซีน
- Regenerate เฉพาะบางช่อง
- เปรียบเทียบหลายเวอร์ชัน

### 3.3 Prompt Only Mode

ระบบต้องทำงานได้แม้ไม่มี API ภาพ วิดีโอ หรือเสียง โดยสร้างเฉพาะ Prompt และข้อมูลทั้งหมดให้ผู้ใช้คัดลอกไปใช้งานกับเครื่องมืออื่น

### 3.4 Full Generation Mode

เมื่อมีการเชื่อม API ผู้ใช้สามารถสั่งสร้างได้ทีละประเภท

- สร้างภาพนิ่ง
- สร้างวิดีโอ
- สร้างเสียงพูด
- รวมเสียงกับวิดีโอ
- ใส่ข้อความไทยและซับไตเติล
- Export ไฟล์สำเร็จ

## 8. แนวทางข้อความโปรโมต

ใช้คำที่เน้นประสบการณ์และบรรยากาศ เช่น

- ช่วยให้ห้องไลฟ์ดูมีชีวิตชีวามากขึ้น
- ช่วยเพิ่มความมั่นใจระหว่างการนำเสนอสินค้า
- ทำให้บรรยากาศการไลฟ์ดูน่าสนใจขึ้น
- เหมาะสำหรับผู้ขายที่ต้องการเริ่มต้นไลฟ์อย่างมั่นใจ
- ทดลองใช้ตามความเหมาะสมของร้าน
- ผลลัพธ์อาจแตกต่างกันตามเนื้อหา เวลา และสินค้า

หลีกเลี่ยง

- รับประกันยอดขาย
- รับประกันขึ้นฟีด
- รับประกันลูกค้าจริง
- ยอดพุ่งแน่นอน
- หลบระบบ
- ปลอดภัย 100%
- ไม่มีวันโดนตรวจ
- กล่าวอ้างว่าเป็นผู้ชมจริง หากไม่มีหลักฐาน
- ปลอมคำรับรองจากลูกค้า
- แสดงตัวเลขผลลัพธ์ที่ผู้ใช้ไม่ได้ระบุ

ระบบต้องมี Disclaimer ที่แก้ไขได้ เช่น

`ผลลัพธ์ขึ้นอยู่กับเนื้อหา สินค้า ช่วงเวลา และรูปแบบการไลฟ์ของแต่ละบัญชี`

- ซีนซึ้งและสร้างแรงบันดาลใจ

## 15. เกณฑ์สำเร็จของระบบ

ระบบถือว่าผ่านเมื่อ

1. สร้างโปรเจกต์ใหม่ได้
2. เลือกตัวละครผู้หญิงไทยอายุ 25–27 ปีเป็นค่าเริ่มต้นได้
3. เลือกหมวดสินค้าและฉากได้
4. สร้างซีนต่อเนื่องได้อย่างน้อย 10 ซีน
5. บทพูดทุกซีนถูกตรวจให้อยู่ระหว่าง 17–20 คำ
6. ข้อความแสดงผลและคำอ่านถูกแยกจากกัน
7. แก้เฉพาะคำอ่านได้โดยไม่เปลี่ยนซับไตเติล
8. คัดลอก Prompt แยกส่วนได้
9. Export Markdown และ JSON ได้
10. ทำงานใน Prompt Only Mode ได้
11. ใช้งานบนมือถือได้
12. Deploy บน Railway ได้โดยไม่เก็บ Secret ใน Repository
