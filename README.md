# Prompt Pumlikes

เว็บแอปสำหรับสร้างไอเดีย Storyboard ซีนต่อเนื่อง Prompt ภาพ Prompt วิดีโอ บทพูดภาษาไทย คำอ่านสำหรับเสียง AI ซับไตเติล และชุดสื่อโปรโมตสำหรับ `pumlikes.com`

## Production

- Web App: `https://prompt-pumlikes-production.up.railway.app/`
- Production Branch: `main`
- Default Language: ภาษาไทย
- Default Format: วิดีโอแนวตั้ง 9:16
- Default Character: ผู้หญิงไทย อายุ 25–27 ปี
- Speech Rule: บทพูดทุกซีนต้องมี 17–20 คำ

## เอกสารที่ AI ผู้พัฒนาต้องอ่าน

1. [`docs/MASTER_SPEC.md`](docs/MASTER_SPEC.md) — เป้าหมาย ระบบ หน้าเว็บ Workflow และข้อกำหนดหลัก
2. [`docs/THAI_VOICE_SPEC.md`](docs/THAI_VOICE_SPEC.md) — ระบบแยกข้อความเขียนกับคำอ่าน การนับคำ และลิปซิงก์
3. [`docs/SCENE_AND_DESIGN_SPEC.md`](docs/SCENE_AND_DESIGN_SPEC.md) — ตัวละคร สถานที่ คลังซีน ภาพ วิดีโอ และแอนิเมชัน
4. [`docs/IMPLEMENTATION_AND_DEPLOYMENT.md`](docs/IMPLEMENTATION_AND_DEPLOYMENT.md) — โครงสร้างระบบ Phase การพัฒนา Railway ความปลอดภัย และเงื่อนไขตรวจรับ

## กฎสำคัญที่สุด

- ข้อความแสดงผลต้องสะกดไทยถูกต้อง
- คำอ่านสำหรับเสียง AI ต้องแยกเป็นอีกช่องหนึ่ง เช่น ข้อความใช้ `ลูกค้า` แต่คำอ่านอาจใช้ `ลูกค๊า`
- ห้ามนำคำอ่านแบบสะกดเลียนเสียงไปใช้เป็นซับไตเติลหรือข้อความบนภาพ
- บทพูดทุกซีนต้องมี 17–20 คำ
- ห้ามให้โมเดลสร้างภาพหรือวิดีโอวาดตัวอักษรไทยเอง ให้สร้างภาพพื้นฐานก่อนแล้ววางข้อความไทยด้วยระบบของเว็บภายหลัง
- ตัวละครเริ่มต้นเป็นผู้หญิงไทยอายุ 25–27 ปี และต้องล็อกหน้าตา เสื้อผ้า ฉาก สินค้า และแสงให้ต่อเนื่องกัน
- ต้องรองรับการเลือกซีนเดี่ยว หลายซีน หรือช่วงซีนต่อเนื่อง
- ใช้ `pumlikes.com` เป็นชื่อแบรนด์หลักในงานที่สร้าง
- ห้ามกล่าวอ้างรับประกันยอดขาย การขึ้นฟีด การหลบระบบ หรือผลลัพธ์ที่ตรวจสอบไม่ได้
- ต้องมีโหมด Prompt Only แม้ยังไม่ได้ตั้งค่า API สำหรับสร้างภาพ วิดีโอ หรือเสียง

## คำสั่งสำหรับ AI ผู้พัฒนา

ให้อ่านเอกสารทั้งหมดก่อนเริ่มแก้ไข Repository ตรวจโครงสร้างเดิมก่อนเขียนโค้ด แบ่งงานตาม Phase ทดสอบ Build และการใช้งานบนมือถือก่อน Push และห้ามใส่ API Key หรือ Secret ลงใน GitHub
